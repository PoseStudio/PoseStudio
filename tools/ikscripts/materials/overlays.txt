# THE OVERLAYS (2026-11-11): images layered over a zone's maps — tattoos, bruises, freckles, makeup —
# driven on the base figure the way the Materials tab's Overlays section drives them:
#   POSESTUDIO_TEST_FIGURE=<figure> tools/ikscripts/run.sh tools/ikscripts/materials/overlays.txt <out> POSESTUDIO_IK_SCRIPT_ASSETS=<assets>
# (the overlay_*.png patterns from tools/materials/make_test_assets.py: each covers the whole UV
# square, so it shows on any zone). `overlay add [image]` puts an overlay on top of the selected
# zone's stack — EMPTY, as the tab's + Add Overlay does, or with its picture — `overlay <n> <field>
# <value>` sets a control in the tab's units (<n> from 0, the lowest layer), `overlay <n> tint r g b`
# its Base Color, `overlay <n> map <color|opacity|metallic|bump|normal|displacement> <image|none>`
# an image (`map opacity` is the Opacity row's map: the overlay's MASK), `overlay <n> name <text>`
# its name, `overlay move <n> <to>`, `overlay remove <n>`; `overlays` counts the zone's stack,
# `overlay.<n>.<field>` reads a control, `overlay.<n>.has.<element>` an image,
# `overlay.<n>.named.<name>` its name (a space written _), `overlayzones` the
# zones the stack is painted on; `metalbaked` the Metallic value (percent) the zone's bound
# metalness was baked for under a metallic overlay, -1 when there is none. Every edit is one undo
# entry; the stack rides the project file.
# An overlay's PLACE is four of its fields, each acting on every image of the overlay together:
# `offsetx` / `offsety` in percent of the map (+x to the right, +y up), `rotation` in degrees
# (+ clockwise on the map) and `scale` in percent of the painted size, both about the overlay's
# own centre.
# The shots are what to LOOK at: dots in the skin (moved half a grid cell; turned and enlarged), a
# tinted glossy band over them, domes in relief.
