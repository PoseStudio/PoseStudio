# DIGITS AND THE FACE (2026-09-28). A finger or a toe dragged moves ITS OWN DIGIT alone, up to where
# it joins the hand or the foot — with or without Ctrl — and nothing else: the hand, the arm and the
# body are asserted still (0.0mm: a bone none of the solve's unknowns move does not move at all).
# The face rig is for expressions and is not posed: a click anywhere on the face selects the HEAD, and
# a drag from there is the head's.
#
# In `view front` she faces the camera: screen-right is her LEFT. Her left hand hangs at her side,
# its palm toward her thigh — screen-left of the hand.

# 1. A fingertip curled toward the palm: the index finger bends, the hand stays.
view front
closeup lHand 0.16
press lIndex3
dragv -0.030 0.015 40 30
report finger_curl
expect grab < 10
expect moved.lHand < 0.01
expect moved.lForeArm < 0.01
expect moved.lMid3 < 0.01
expect hips < 0.01
expect head < 0.01
expect steps < 1
expect jump < 15
shot 401_front_finger_curl
release

# 2. The same finger pulled 40cm up, far beyond its reach: it points after the cursor as far as
# its joints allow, and the arm does not come along.
press lIndex3
dragv 0 0.40 40 30
report finger_far
expect moved.lHand < 0.01
expect moved.lShldr < 0.01
expect hips < 0.01
expect steps < 1
expect jump < 40
shot 402_front_finger_far
release
reset

# 3. The thumb, by its tip.
view front
closeup lHand 0.16
press lThumb3
dragv -0.02 -0.02 40 30
report thumb
expect moved.lHand < 0.01
expect moved.lIndex3 < 0.01
expect hips < 0.01
shot 403_front_thumb
release
reset

# 4. Ctrl + drag on a finger is the same drag: the digit alone.
view front
closeup lHand 0.16
cpress lMid3

report finger_ctrl
expect moved.lHand < 0.01
expect moved.lIndex3 < 0.01
expect hips < 0.01
shot 404_front_finger_ctrl
release
reset

# 5. The back of the hand is the HAND's: the arm follows, the body's drag as ever.
view front
closeup lHand 0.30
press lHand
dragv 0.10 0.10 40 30
report hand_itself
expect grab < 5
expect moved.lForeArm > 20
shot 405_front_hand_itself
release
reset

# 6. A toe raised: the big toe bends up, the foot and the body stay.
view front

report toe_up
expect moved.lFoot < 0.01
expect moved.rFoot < 0.01
expect hips < 0.01
expect steps < 1
expect lowest > -2
shot 406_front_toe_up
release
reset

# 7. The FACE: clicks on the eye, the jaw, the nose and an ear each select the head.
view front
closeup head 0.22
click lEye
expect selected.head == 1
click lowerJaw
expect selected.head == 1
click lEar
expect selected.head == 1
view right
click head
expect selected.head == 1

# 7b. THE HAND (2026-10-28): the carpals are the hand's own flesh — a click on any of them, on the palm
# or the back of the hand, selects the HAND, and the carpals light with it; the ball and the mid-foot
# are the foot's the same way. (Before this the hand's flesh was split among four selectable carpals,
# and "the hand node can be difficult to select".)
view front
closeup lHand 0.22
click lCarpal1
expect selected.lHand == 1
expect lit.lCarpal1 == 1
expect lit.lCarpal2 == 1
click lCarpal3
expect selected.lHand == 1
click lCarpal2@0.5
expect selected.lHand == 1
shot 406b_hand_by_its_carpals
view right
closeup lFoot 0.2
click lMetatarsals
expect selected.lFoot == 1
expect lit.lMetatarsals == 1
# (The ball's own pixel is a toe's skin from the side — a toe, rightly: click the mid-foot's body.)
click lMetatarsals@0.5
expect selected.lFoot == 1
reset

# 8. ... and a drag that begins on the face is the head's drag: the head goes, the eye does not turn.
view front

expect grab < 15
expect head > 20
expect euler.lEye.x == 0
expect euler.lEye.y == 0
expect euler.lowerJaw.x == 0
expect steps < 1
shot 407_front_face_drag
release
reset

# 9. EACH JOINT OF A DIGIT LIGHTS ITS OWN PART (`lit.<bone>`: the selection highlight tints that
# bone's flesh). A finger's first two joints used to light together whichever was clicked — the
# second, a hinge with two locked channels, was taken for the first's twist bone — and nobody
# could tell which joint was selected. The same for a toe's two joints.
view front
closeup lHand 0.16
click lIndex1@0.5
expect selected.lIndex1 == 1
expect lit.lIndex1 == 1
expect lit.lIndex2 == 0
expect lit.lIndex3 == 0
shot 408_index_joint1_selected
click lIndex2@0.5
expect selected.lIndex2 == 1
expect lit.lIndex2 == 1
expect lit.lIndex1 == 0
expect lit.lIndex3 == 0
shot 409_index_joint2_selected
click lIndex3
expect selected.lIndex3 == 1
expect lit.lIndex3 == 1
expect lit.lIndex2 == 0
shot 410_index_joint3_selected
view top
closeup lFoot 0.16
click lSmallToe2@0.5
expect selected.lSmallToe2 == 1
expect lit.lSmallToe2 == 1
expect lit.lSmallToe2_2 == 0
shot 411_toe_joint1_selected
click lSmallToe2_2 0 10
expect selected.lSmallToe2_2 == 1
expect lit.lSmallToe2_2 == 1
expect lit.lSmallToe2 == 0
shot 412_toe_joint2_selected
# A limb's TWIST bone still lights with its bend bone: a grabbed thigh lights the whole thigh.
view front
click lThigh
expect lit.lThigh == 1
expect lit.lThighTwist == 1
quit
