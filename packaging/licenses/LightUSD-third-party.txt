LightUSD (formerly TinyUSDZ) - third-party code compiled into PoseStudio
========================================================================

LightUSD, https://github.com/lighttransport/tinyusdz, carries the code of
other projects in its source tree. PoseStudio builds LightUSD as a static
library with its optional features off; the components below are the ones
that build compiles or includes. LightUSD's LICENSE.3rdparty file is the
authoritative list. stb_image, tinyexr, tinyobjloader and nlohmann/json
appear in their own files in this folder.
